# Field Marshal badge and artwork

## Visual direction
- Create original transparent badge artwork for **Field Marshal**: a formal command shield with a marshal star, laurel detailing, and a deep crimson, antique-gold, and gunmetal palette.
- Keep it visually distinct from the General gold shield and legible at both plan-card and compact request-row sizes.
- Use the generated artwork as a project asset with meaningful alternative text.

## Where it appears
- Replace the General badge fallback on the Field Marshal plan card and every shared plan-badge display, including active investments and member profiles.
- Add the Field Marshal artwork to the member payout panel beside its title.
- Identify Field Marshal payout requests from their existing request note and show the artwork with a **Field Marshal** label in the admin withdrawal table and approval/rejection dialogs.
- Leave ordinary withdrawal requests unchanged.

## Supporting styling
- Give Field Marshal active-investment labels and surfaces their own crimson/gold treatment instead of the generic fallback styling.
- Preserve the current layout and behavior; this change is artwork and presentation only.

## Verification
- Check the Investment Plans card and payout displays at mobile and desktop sizes.
- Confirm Field Marshal requests receive the new badge while General and ordinary withdrawals retain their existing presentation.
- Run the project type check after integration.
